# Research provenance

This utility originated in the ReMaverick research workflow for SPLITGATE: Arena Reloaded preservation.

ReMaverick's evidence policy is to publish observations, metadata, hashes and reproducible procedures rather than proprietary game files. AI-assisted work is permitted there, but generated interpretations are treated as hypotheses until independently checked against evidence.

For this release, AI assistance was used to restructure and document the existing intake script, design the Windows wrapper, create synthetic regression fixtures and review the privacy boundary. The implementation was then executed locally against synthetic fixtures and against the supplied private PortalWars2 prefix before release packaging.

Do not treat this statement as evidence about the game itself. It documents the provenance of this software.
