# Changelog

## v1.0.0 — 2026-09-03

Initial public release.

- Extracted the PortalWars2 prefix intake utility from the ReMaverick research repository.
- Added Windows `%LOCALAPPDATA%` automatic discovery for use against a broader user LocalAppData tree.
- Added a one-click Windows launcher that writes timestamped output beside the launcher.
- Added account/session identifier redaction for inventory paths and cache metadata.
- Added optional SHA-256 calculation and a faster `--no-hash` mode.
- Added optional source-URL preservation behind `--allow-source-urls`.
- Added deterministic synthetic fixtures and regression tests.
- Added privacy, research-provenance and output-format documentation.
